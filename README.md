# 铁路足迹

参照飞行足迹项目制作的火车版本。沿用深色地图风格，提供真实铁路轨迹回放、行程筛选、统计图表、行程搜索和文件导入导出，支持区域地图与可旋转的地球视图。界面、提示、表格模板及项目说明均使用中文。

## 本地启动

需要 Node.js 22.13 或更新版本。

```sh
git clone https://github.com/Eigenoperator/train-atlas.git
cd train-atlas
npm ci
npm run dev -- --host 127.0.0.1 --port 3001
```

Windows 用户也可以从 PowerShell 运行 `./Start-TrainAtlas.ps1`，然后打开 <http://localhost:3001/>。按 Ctrl+C 停止服务。

首次启动显示虚构示例行程。通过页面的导入功能读取自己的行程表格；也可以将导出的 JSON 保存为 `.local/train-data.json`，本地开发服务会自动加载这个文件。`.local` 目录不纳入版本控制。

个人行程文件已排除在版本控制和生产构建之外。生产构建仅内置 6 段虚构示例行程；用户可自行导入文件。导入文件只在当前浏览器中解析，刷新页面后不会保留，建议下载整理后的数据备份。

## 导入格式

支持 `.xlsx`、`.xls`、CSV 和 JSON。电子表格读取第一个工作表。日期、上车站和下车站为必填字段；同时兼容既有英文表头及英文车站别名。

| 中文表头 | 说明 |
|---|---|
| 日期 | 支持八位年月日、标准日期字符串或电子表格日期序号 |
| 车次 | 支持 G、D、C 等车次 |
| 上车站 | 实际上车的车站 |
| 上车时间 | 支持 1700、17:00 或电子表格时间小数 |
| 下车站 | 实际下车的车站 |
| 下车时间 | 当地到达时间 |
| 始发站 | 列车全程的始发站 |
| 终到站 | 列车全程的终到站 |
| 座位 | 保留原始记录，包括“无座”和前导零 |
| 跨天数 | 可选，取值为 0 至 30 |

数值 `20260520` 按年月日解析，数值 `1700` 按 17:00 解析。未指定跨天数且到达时间早于出发时间时，默认次日到达；超过 24 小时的旅程应填写跨天数。时长按记录中的时钟时间计算，不做跨时区换算。

地图和车站统计使用实际上下车站；列车全程的始发站、终到站仅作为记录信息。列车类型依据车次前缀分类，不推断动车组车型。座位分布按记录中的座位字母统计，不推断席别或靠窗、靠过道位置。

未知车站的行程仍保留在行程簿和时长统计中，并显示中文提示。可通过 JSON 的 `stations` 字典补充车站信息：键为车站名，值包含 `name`、`city`、`latitude`、`longitude`，以及可选的 `source`、`aliases`。只有车站坐标不足以绘制铁路线路，还需对应的轨道几何数据。

表格模板：`public/templates/train-atlas-template.csv`，使用中文表头及 UTF-8 编码标记，方便直接用电子表格软件打开。JSON 字段说明：`public/api/train-atlas.schema.json`。字段标识遵循原有接口约定，说明文字使用中文。

## 真实铁路轨迹

路线沿开放街图的真实铁路轨道绘制，不使用起终点之间的示意弧线。`app/data/rail-routes.json` 内置 19 条铁路线路。轨迹由 BRouter 的铁路模式计算，以途经站及高铁、普铁线路约束走向；路段标记均为 `railway=rail`。长距离线路分段获取，仅在相邻端点间距不超过 2 米时拼接。

播放位置依据轨道节点之间的累计里程插值，返程反向播放同一条轨迹。里程采用路径引擎返回的轨道长度，每段行程取整至公里后汇总，属于几何估算，不等于票面里程。乘车时长直接来自原始记录。可导出带来源信息的铁路 GeoJSON 文件。

这些线路依据现有轨道和途经站重建，并非历史列车的定位实录。实际运行可能因历史调图、绕行、站内股道及上下行轨道而有所不同。同一站点组合但车次未匹配时，会明确提示使用已知线路；没有轨道数据时不绘制连线，也不估算里程。

主要线路包括：

- 京沪高铁：区分上海站联络线与上海虹桥站。
- 沪宁城际：区分苏州、镇江与京沪高铁上的苏州北、镇江南。
- 青岛方向：经丹徒、扬州东、淮安东、连云港、日照西、青岛西及红岛。
- 千岛湖方向：经上海松江、苏州南、湖州东、杭州西及杭昌高铁。
- 香港西九龙至福田：广深港高铁。

每条线路记录来源链接、获取时间、途经站坐标、铁路标记及参考时刻表。车站坐标保留维基百科或维基数据来源。线路吸附另参考[基于开放街图的中国高铁几何数据](https://github.com/linroger/china-hsr-simulation/blob/main/public/hsr-rails.geojson)。现行时刻表用于判断走向，不能证明历史列车的精确路径；沪苏湖相关运行调整可参见[铁路部门公告报道](https://news.cctv.cn/2025/01/05/ARTI34cFBnDEa86fhxIewffe250105.shtml)。

铁路数据 © [开放街图贡献者](https://www.openstreetmap.org/copyright)，采用开放数据库许可协议（ODbL 1.0）；路径计算使用 [BRouter](https://brouter.de/)。轨迹随项目内置，查看地图及导入行程无需向外部路径服务发送个人记录。

## 导入接口

`GET /api/v1/import` 返回中文接口说明。`POST /api/v1/import` 接受行程数组，或 `{ "journeys": [...], "stations": {...} }`，返回整理后的数据和中文提示。

接口不保存行程。调用接口会将提交内容发送到服务器；浏览器内的文件导入不调用此接口。单次请求限制为 5 兆字节、5,000 条记录，无效记录会给出提示。
